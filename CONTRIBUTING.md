# Contributing

Thank you for your interest in the Daily SwiftUI Lab.

1. Open an issue describing a bug or focused enhancement.
2. Create a topic branch and keep changes small.
3. Add unit tests for changes to snapping or sizing.
4. Run \`swift test\` before opening a pull request.
5. Include accessibility and Reduce Motion considerations for UI changes.

Please keep explanations and source comments in English, and do not submit secrets, private user data, or proprietary code.
